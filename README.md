# نظام الاختبارات — مركز صلة الإتقان للتدريب

موقع اختبارات تحليلية بنمط NEBOSH Open Book لدورات السلامة والصحة المهنية
(أوشا 30 · هازووبر 40 · تشارترد م3 · الرفع والتربيط · آيوش).

**الإصدار الحالي: v25** — آخر تحديث 2026-07-30

## البنية

الموقع كله ملف واحد `index.html` بدون خادم خاص:

- الواجهة: React 18 (تُترجم في المتصفح عبر Babel Standalone)
- قاعدة البيانات: Supabase — جداول `exam_subs` و`exam_meta` و`exam_courses`
- الشهادات: Firebase Firestore — مجموعة `certificates` يقرؤها موقع التحقق `verify.silatalitqan.com`
- نسخة احتياطية محلية في المتصفح عند انقطاع الاتصال

## أبرز الميزات

- دخول المتدرب ببيانات الهوية ورقم طلب سلة، ورمز دخول خاص لكل دورة
- اختبار بمؤقت (افتراضي 24 ساعة) مع حفظ تلقائي وتمديد فوري من المدرب
- سيناريوهان لكل دورة بنافذة وقت واحدة مع تنقّل حر بينهما
- طلبات إعادة الدخول وطلبات فتح الاختبار للتعديل بموافقة المدرب
- لوحة مدرب كاملة: تصحيح بمعايير، إحصائيات، إدارة الدورات والأسئلة ورموز الدخول، تصدير Excel، أرشفة شهرية
- إصدار شهادة تلقائي عند اعتماد النجاح مع رقم تحقق

## التشغيل والنشر

الملف يعمل على أي استضافة ملفات ثابتة (GitHub Pages / Cloudflare Pages).
ملف `index.html` في جذر المستودع = جاهز للنشر مباشرة.
